# Game Translator (EN → TH) — เวอร์ชัน 1

โอเวอร์เลย์แปลบทสนทนาเกมแบบเรียลไทม์: จับภาพเฉพาะกรอบข้อความ → Windows OCR → Gemini → แสดงคำแปลไทยทับเกม
เขียนด้วย Rust ไม่มี GC, RAM ราว 10-30 MB, ในโหมด hotkey โปรแกรมหลับรอปุ่มและไม่กิน CPU เลย

## วิธีสร้างโปรแกรม (ทำครั้งเดียว)

1. ติดตั้ง **Visual Studio Build Tools** (เลือก "Desktop development with C++")
   https://visualstudio.microsoft.com/visual-cpp-build-tools/
2. ติดตั้ง **Rust** จาก https://rustup.rs (เลือกค่าเริ่มต้น แล้วเปิด Terminal ใหม่)
3. เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน
   ```
   cargo build --release
   ```
4. ได้ไฟล์ `target\release\game-translator.exe` (คัดลอกไปไว้โฟลเดอร์ไหนก็ได้)

## ไอคอนโปรแกรม

ไอคอนอยู่ที่ `icon.ico` และถูกฝังเข้าไฟล์ .exe ตอน build (ผ่าน `build.rs` + `app.rc`)
อยากเปลี่ยนรูป: แทนที่ `icon.ico` (ไฟล์ .ico หลายขนาด 16-256 px) แล้วสั่ง `cargo build --release` ใหม่
ถ้าเปลี่ยนแล้วไอคอนใน File Explorer ยังเป็นรูปเดิม ให้เปลี่ยนชื่อไฟล์ .exe หรือรีสตาร์ท Explorer (Windows จำไอคอนเก่าไว้)

## วิธีใช้

1. ขอ API key ฟรีที่ https://aistudio.google.com/apikey
2. รัน `game-translator.exe` ครั้งแรกจะสร้าง `config.toml` ข้างไฟล์ ให้ใส่ `api_key` แล้วเปิดใหม่
3. ตั้งเกมเป็น **Borderless Window** (Exclusive Fullscreen จะจับภาพ/แสดงผลทับไม่ได้)
4. ในฉากที่มีข้อความขึ้นอยู่ กด **F5** แล้ว **ลากเมาส์ครอบข้อความ** ที่ต้องการแปล ปล่อยเมาส์เพื่อบันทึก
   (จอจะหยุดนิ่งชั่วคราวระหว่างเลือก ข้อความหายไปแล้วก็ไม่เป็นไร Esc หรือคลิกขวา = ยกเลิก)
   โปรแกรมจำกรอบไว้ใน config.toml ให้เอง ครั้งหน้าไม่ต้องเลือกใหม่
   จากนั้นกด **F6** เพื่อตรวจว่า OCR อ่านข้อความในกรอบได้ไหม (บันทึกภาพเป็น `debug_capture.bmp`)
5. เล่นเกมแล้วกดปุ่ม

| ปุ่ม | หน้าที่ |
|---|---|
| F8 | แปลข้อความในกรอบทันที |
| F7 | แปล + อธิบายคำศัพท์/สแลง/สำนวน |
| F5 | ลากเมาส์เลือกกรอบข้อความ |
| F6 | ตรวจกรอบจับภาพ (ดีบัก) |
| F9 | ซ่อนคำแปล |
| Ctrl+Shift+Q | ปิดโปรแกรม |

ตั้ง `mode = "auto"` ใน config.toml ถ้าอยากให้แปลอัตโนมัติเมื่อข้อความเปลี่ยน
- เทียบภาพในกรอบทีละพิกเซลแบบเบา ๆ ทุก `poll_ms` เมื่อภาพเปลี่ยนแล้วนิ่ง จึง OCR และแปล
- อ่านกรอบซ้ำทุก `auto_recheck_ms` เป็นตาข่ายกันพลาด (ถึงตรวจไม่พบว่าภาพเปลี่ยน ก็ยังได้คำแปล)
- ถ้าอ่านไม่ได้ข้อความ จะลองปรับคอนทราสต์/กลับสีภาพแล้วอ่านซ้ำเอง
- ข้อความเดิมที่ OCR อ่านเพี้ยนเล็กน้อยจะไม่ถูกแปลซ้ำ และมี cache + หน่วงเวลาเรียก API (`min_api_interval_ms`) กันโควตาฟรีหมด

## ใส่ศัพท์เฉพาะ

เพิ่มใต้ `[glossary]` ใน config.toml เช่น `"Aldric" = "อัลดริก"` เพื่อให้ชื่อตัวละครแปลคงที่

## แก้ปัญหา

- **ไม่พบ OCR ภาษาอังกฤษ**: Settings → Time & Language → Language → เพิ่ม English (United States) แล้วรีสตาร์ท
- **API 404**: ชื่อ `model` ใน config.toml ไม่ถูกต้อง ดูชื่อรุ่น Flash-Lite ล่าสุดใน AI Studio
- **โควตาเต็ม (429)**: รอสักครู่ หรือใช้โหมด hotkey / เพิ่ม `min_api_interval_ms`
- **อ่านตัวหนังสือพลาด**: ลอง `ocr_scale = 3` หรือย่อกรอบให้เหลือเฉพาะข้อความ
- **หน้าต่างดำ/จับภาพไม่ได้ในบางเกม**: ใช้ Borderless Window
